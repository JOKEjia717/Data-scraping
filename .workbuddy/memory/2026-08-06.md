- **Vue 3 已从实例移除 `$set`/`$delete`**（Vue 2 才有）。Vue 3 Proxy 响应式对新增属性自动追踪，直接用 `obj[k]=v` / `delete obj[k]`。初版误用 `this.$set` 会导致运行时报错白屏——已改掉。

## 白屏调试（2026-08-06 深夜，关键坑 — 可复用）
- **现象**：三大板块重写后页面全白（强刷仍白），但 HTML/Vue/静态托管/curl 全部正常，`node --check` 与 `Vue.compile` 模板语法也都通过。
- **根因**：Vue 3 Options API 模板**只能访问实例属性**（data/computed/methods/props/globalProperties），访问不到模块作用域外的顶层 `const`。app.js 把 `ICONS`/`PLATFORM_NAMES`/`PLATFORM_COLORS`/`PLATFORM_ORDER` 定义为模块顶层 const，模板里直接 `v-html="ICONS[item.icon]"`、`v-for="pf in PLATFORM_ORDER"` → 这些在实例上是 undefined。侧边栏第一个 nav 的 `icon` 恰好是 `"overview"`，于是 `ICONS['overview']` = `undefined['overview']` → 抛 `TypeError: Cannot read properties of undefined (reading 'overview')`，根组件渲染中断 → 白屏。
- **修复**：mount 前注入全局属性（子组件也能继承访问）：
  ```js
  const app = createApp(App);
  app.config.globalProperties.ICONS = ICONS;
  app.config.globalProperties.PLATFORM_NAMES = PLATFORM_NAMES;
  app.config.globalProperties.PLATFORM_COLORS = PLATFORM_COLORS;
  app.config.globalProperties.PLATFORM_ORDER = PLATFORM_ORDER;
  app.component(...).mount("#app");
  ```
- **调试手法（最准）**：用 **jsdom + Vue 开发版(vue.global.js)** 在 Node 里真实 `window.eval(vue+app)` 挂载，捕获 `vc.on('error'/'jsdomError')` 与 `window.onerror`。开发版 Vue 的报错带组件名 `<App>` 与精确表达式位置；生产版只给简略信息，**不要依赖**它。也别用 `Vue.compile`（只验模板语法不验渲染）或假 window 模拟环境（会漏真实运行时错误）。
- **jsdom 环境坑**：①jsdom 装到受管 node 工作区 `C:\Users\xu\.workbuddy\binaries\node\workspace`（`npm install jsdom`）；②调试脚本放该目录运行才能 `import { JSDOM } from 'jsdom'` 自动解析（Git Bash 下 `pathToFileURL('/c/...')` 会被混成 `C:/c/...` 解析失败，改用 `C:/...` Windows 绝对路径或 `createRequire`）；③**mock fetch 必须纯本地返回 JSON + 末尾 `process.exit(0)`**，否则 Node 原生 fetch 到 localhost 的 keep-alive 连接会让进程挂起、前台命令超时转后台。
- **白屏排查顺序**：①服务在线 ②HTML/Vue/JS 静态可访问 ③`node --check` 语法 ④`Vue.compile` 模板语法 ⑤jsdom+dev-build 抓运行时渲染错误（最准）。
