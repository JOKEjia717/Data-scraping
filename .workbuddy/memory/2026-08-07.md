## 12:41 用户反馈"Tab 栏还是没出来" — Vue 3 methods vs computed 关键区别

- **现象**：用户多次强制刷新后，铃铛出来了（新版 JS 确实加载了），但 Tab 栏按钮（`tab-bar` / `tab-pill`）完全不显示。品牌诊断页面只显示「实时耗时趋势」标题和一条任务卡，没有 Tab 按钮。
- **根因（第三类 Vue 3 陷阱）**：`tabConfig`、`groupedByPlatform`、`tabTasks` 三个属性被放在了 `methods` 里，但在模板中以**不带括号的方式引用**：
  - `v-for="tab in tabConfig"` → 遍历的是**函数本身**而非调用返回的数组 → 空迭代
  - `v-for="(brands, pf) in groupedByPlatform"` → 同上
  - `Object.keys(groupedByPlatform)` → 对函数取 keys → 空对象
- **Vue 3 核心规则**：
  - **methods** 中定义的函数在模板中不带 `()` 时 = 函数引用（不是调用结果）
  - **computed** 中定义的属性在模板中引用 = 自动求值后的结果
  - 模板中的 `v-for` 需要可迭代**值**，不能用函数引用
- **连带 bug**：切换到 DIAGNOSIS 后还崩了 `taskClass(t)` — `t.status` 对 `undefined` 的任务报错。用 `(t.status | 0)` 防御 + `groupedByPlatform` 内 `if (!t || !t.executionId) continue` 过滤 + 模板 `tasks.filter(x=>x)` 三重防御。
- **修复**：
  1. 把 `tabTasks`、`groupedByPlatform`、`tabConfig` 从 `methods` 移到 `computed`
  2. `taskClass`/`isStale` 加 `(t.status | 0)` 防御 undefined
  3. `groupedByPlatform` computed 内跳过无效任务
  4. 模板 v-for 加 `.filter(x=>x)`
- **验证（jsdom + vm context，真实 API 数据，切换到 DIAGNOSIS）**：
  - tab-bar: ✅ | tab-pill: 4个 ✅ | grouped-list: ✅ | pg-platform: 2个 ✅
  - brands: 其他/阿里巴巴/阿里云对象存储OSS ✅ | task-cards: 9 ✅ | errors: 0 ✅

## 12:47 taskClass / isStale undefined.status 崩溃修复

- **现象**：用户截图控制台 2 个红色报错 `TypeError: Cannot read properties of undefined (reading 'status')`，均来自 `taskClass`（app.js:940）。
- **根因**：上次修复用了 `(t.status | 0)` 来防御，但 `| 0` 只能在 `t.status` 已求值后处理 `NaN`/`null`。当 `t` 本身是 `undefined` 时，`undefined.status` 直接抛 TypeError，根本走不到 `| 0`。
- **修复**：
  - `taskClass(t)`: `(t.status | 0) !== 1` → `!t || (t.status | 0) !== 1`
  - `isStale(t)`: 同样加 `!t ||` 前置守卫
- **缓存版本**: `?v=20260807d`
- **教训**：Vue 模板中 v-for 过滤后仍可能传入 undefined 给方法调用；所有接收数据参数的方法必须做 null guard（先检查参数本身是否存在，再访问其属性）。

## 13:04 extractBrand 再次崩溃 — BRAND_PARENTS 在 methods 中未挂载

- **现象**：`TypeError: Cannot read properties of undefined (reading '阿里云对象存储OSS')`，在 `extractBrand` 的 `this.BRAND_PARENTS[raw]` 处。
- **根因**：Vue 3 Options API 的 `methods` 对象中，**只有函数属性会被挂载到组件实例**（可通过 `this.xxx` 访问）。非函数属性（如对象/字符串）会被忽略。`BRAND_PARENTS` 是个对象不是函数 → `this.BRAND_PARENTS` 为 `undefined`。
- **修复**：将 `BRAND_PARENTS` 从 methods 移到**模块级常量**（与 `PLATFORM_NAMES`/`ICONS` 同级），`extractBrand` 直接引用 `BRAND_PARENTS`（不加 `this.`）。globalProperties 版本同步更新。
- **教训**：Vue 3 methods 对象只绑定函数。数据/配置常量应放在模块级或 data() 中。
- **缓存版本**：`?v=20260807h`
