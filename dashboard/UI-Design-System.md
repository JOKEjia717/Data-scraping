# 运营台 · UI 设计方案（Design System Spec）

> 设计方向：**精密工业风 / Precision Industrial**
> 目标用户：运营 / 数据分析同学，每日监控 RPA 任务（品牌诊断 / 数据监测 / 风格监测）
> 气质：清爽、克制、专业、可信赖——符合 B 端用户习惯，不炫技

---

## 1. 设计原则

| 原则 | 说明 |
|---|---|
| **层级分明** | 用留白 + 字重 + 色彩层级区分信息主次，而非堆边框 |
| **语义清晰** | 四种任务状态用固定色 + 圆点，全站统一，零歧义 |
| **渐进披露** | 平台 → 品牌 → 问题 三级折叠，默认收起，按需展开 |
| **克制用色** | 单一主色（azure），语义色仅用于状态，避免彩虹噪声 |
| **顺应习惯** | 左侧导航 + 顶栏 + 卡片/表格 的经典 B 端布局，降低学习成本 |

---

## 2. 色彩系统（Color Tokens）

采用 **oklch** 色彩空间，中性阶偏冷墨蓝，避纯黑纯白。

### 主色
- `--azure` `oklch(0.58 0.150 252)` — 主操作、强调、激活态
- `--azure-strong` `oklch(0.52 0.165 252)` — hover / 文字强调
- `--azure-soft` `oklch(0.955 0.030 252)` — 激活背景、聚焦环

### 语义状态色（全站统一）
| 状态 | Token | oklch | 用途 |
|---|---|---|---|
| 运行中 | `--run` | `0.60 0.130 240` | 进行中任务 |
| 待运行 | `--wait` | `0.74 0.135 72` | 排队等待 |
| 已完成 | `--done` | `0.66 0.140 152` | 执行成功 |
| 失败 | `--fail` | `0.60 0.200 22` | 需关注 |

> 对比度均满足 **WCAG AA**（正文 4.5:1，大字 3:1）。

### 中性阶
`--ink-50`（背景）→ `--ink-900`（最深文字），12 级，偏冷调。
深色模式背景 `oklch(0.175 0.012 262)`（深墨蓝，**非纯黑**）。

## 3. 字体排印（Typography）

| 角色 | 字体 | 用途 |
|---|---|---|
| Display / 标题 | **Space Grotesk** | 页面标题、品牌名、KPI 数字（几何感、辨识度高） |
| Body / 正文 | **IBM Plex Sans** | 正文、导航、按钮（中性、长文易读） |
| Mono / 数据 | **JetBrains Mono** | 任务 ID、耗时、百分比（等宽对齐） |

**字号阶梯**（clamp 流式）：`12 / 13 / 14 / 15 / 18 / 30 / 44` px
字重：`400 / 500 / 600 / 700`

---

## 4. 间距与栅格（Spacing & Grid）

- 基数 **4pt**，常用：8 / 16 / 24 / 32 / 44 px
- 刻意变化间距制造节奏（如 KPI 内 6px、卡片间 16px、区块间 32px）
- 内容最大宽度 **1180px**，居中
- 12 列弹性栅格，断点：920px（KPI 2列）、760px（移动端抽屉）

---

## 5. 组件库（Components）

### 导航
- 左侧固定导航，分组（监控 / 分析），激活项用主色软底 + 主色文字
- 每项右侧 `nav-count` 徽标显示数量

### 顶栏 Topbar
- 页面标题 + 全局搜索（胶囊 Input）+ 主题切换 + 通知铃（红点角标）
- 毛玻璃 `backdrop-filter`，滚动时常驻

### KPI 卡片
- 标签（带状态点）+ 大号 Display 数字 + 趋势说明
- hover 左侧出现主色强调条

### Tabs（分段控件）
- 胶囊容器 + 滑动激活态，每项带状态点与数量徽标

### 三级分组列表（核心）
```
平台（group）
 └─ 品牌（brand-row，可折叠）
     └─ 问题（task，状态药丸 + ID）
```
- 品牌行点击展开/收起，箭头 `▸ → ▾` 旋转 90°，`grid-template-rows` 平滑过渡
- 默认全部收起，降低初始认知负载

### 状态药丸 Pill
- 圆角胶囊 + 左侧状态点，四态固定配色

### 数据表 Table
- 表头浅底、行 hover 高亮，ID/数字用 Mono
- 不套多重边框，靠分隔线保持轻量

### 空状态 Empty
- 虚线框 + 线性图标 + 一句说明，**有教育意义**（告知下一步）

---

## 6. 交互与动效（Motion）

- 缓动统一：`cubic-bezier(0.22, 1, 0.36, 1)`（ease-out-quart，沉稳不回弹）
- 状态变化用过渡，不动画布局重排
- 折叠展开：`grid-template-rows: 0fr → 1fr` 平滑展开
- 主题切换：整页背景/文字 0.4s 过渡
- 触控目标 ≥ 38px（图标按钮），满足移动端

---

## 7. 响应式策略（Responsive）

| 断点 | 布局 |
|---|---|
| ≥ 920px | KPI 4 列，侧栏常驻 |
| 760–920px | KPI 2 列 |
| < 760px | 侧栏隐藏（抽屉），搜索收起，单列 |

- 移动端**不隐藏关键功能**（导航转为抽屉、状态/筛选保留）
- 优先容器查询 `@container`，避免断点硬切

---

## 8. 深色模式（Dark）

- 通过 `data-theme="dark"` 切换，令牌整组替换
- 深色非纯黑（深墨蓝），降低眩光，适合监控大屏长时间盯看
- 语义色在深底上提亮饱和度，保持可辨识

---

## 9. 可访问性（A11y）

- 对比度：WCAG AA（正文 4.5:1）
- 键盘：所有交互元素可聚焦，`:focus-visible` 主色环
- 触控：图标按钮 ≥ 38px
- 文案：每个词有存在价值，空状态给出下一步指引
